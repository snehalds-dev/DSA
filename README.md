# DSA
This repository includes coding problems and solutions for Data structures and Algorithms

### To Run Java code in terminal:
- javac filename.java
- java filename

### To clone the Repo: 
git clone -b branchName https://github.com/snehalds-dev/DSA.git

### To switch branch:
git checkout -b develop origin/develop

### To downloads latest changes from GitHub (remote repo) without changing local files:
git fetch

### To download AND merge latest changes into your current branch:
git pull
(Equivalent to git fetch + git merge)

### To stage the files for commit:
git add filename.java
git add . (to add all the files)

### To save the snapshot of changes locally:
git commit -m "message"

### To upload the changes to github:
git push

### To check status of changes:
git status

### To check commit history:
git log

### To see the branches:
git branch
